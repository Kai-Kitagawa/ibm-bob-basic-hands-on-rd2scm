# 準備と設定

チュートリアルに必要なリソースを準備し、IBM Bobの基本操作を理解します。

## 環境準備

## 1. チュートリアルデータの取得

### 1-1. Lab 4: ソース管理　を実施する場合

#### 1-1-1. GitHubリポジトリのFork

元のリポジトリを自分のGitHubアカウントにForkします。

**前提条件:**
- GitHubアカウントを持っている

**手順:**

1. Webブラウザで元のリポジトリにアクセスする
   - URL: `[リポジトリURL - 後日差し替え予定]`
2. 画面右上の「Fork」ボタンをクリック
3. Fork先のアカウントを選択（通常は自分のアカウント）
4. 「Create fork」をクリック
5. Forkが完了するまで待つ

**確認ポイント:**
- 自分のGitHubアカウントにリポジトリがコピーされている
- リポジトリ名の下に「forked from [元のリポジトリ名]」と表示されている

#### 1-1-2. devブランチの作成

Forkしたリポジトリのmainブランチから、新しくdevブランチを作成します。

**手順:**

1. Forkしたリポジトリのページで、ブランチドロップダウン（「main」と表示されている部分）をクリック
2. テキストボックスに「dev」と入力
3. 「Create branch: dev from 'main'」をクリック

**確認ポイント:**
- ブランチドロップダウンに「dev」ブランチが表示される
- 現在のブランチが「dev」になっている

#### 1-1-3. GitHubリポジトリのクローン

Forkしたリポジトリのdevブランチをローカルにクローンします。

**前提条件:**
- Gitがインストールされている
- 1-1-1と1-1-2が完了している

**手順:**

1. Bob IDEを起動する
2. コマンドパレットを開く
   - Windows/Linux: `Ctrl+Shift+P`
   - Mac: `Cmd+Shift+P`
3. 「Git: Clone」と入力して選択する
4. Forkしたリポジトリ（自分のアカウント）のURLを入力する
   - 例: `https://github.com/[あなたのユーザー名]/[リポジトリ名]`
5. クローン先のディレクトリを選択する
6. クローンが完了したら、「Open」をクリックしてプロジェクトを開く
7. devブランチに切り替える
   - 画面左下に表示されている現在のブランチ名（「main」）をクリック
   - 上部に表示されるブランチ一覧から「dev」を選択

**確認ポイント:**
- EXPLORERにリポジトリのファイルが表示される
- 必要なファイル（Bob.svg、qa.md、PROMPT.mdなど）が確認できる
- 画面左下のブランチ名が「dev」になっている

### 1-2. Lab 4: ソース管理　を実施しない場合

#### 1-2-1. GitHubリポジトリへアクセス

Webブラウザを開き、リポジトリにアクセスします：https://github.com/r-nakayamasan/Bob-workshop

#### 1-2-2. データのダウンロード

1. 「Code」ボタンをクリックして展開
2. 「Download ZIP」をクリック

「Bob-workshop-main.zip」という名前のファイルがダウンロードされます。

#### 1-2-3. ファイルの展開

1. ダウンロードフォルダに移動
2. 「Bob-workshop-main.zip」を右クリック
3. 「すべてのファイルを展開」(Windows) または「展開」(Mac) をクリック

注意: .zipファイルではなく、展開後のフォルダを使用します。

#### 1-2-4. 作業ディレクトリへ移動

展開後の「Bob-workshop-main」フォルダを、作業しやすい場所（デスクトップなど）にコピーします。

**手順:**

1. 「Bob-workshop-main」フォルダをコピー
2. デスクトップまたは任意の作業場所にペースト

## 2. ファイル構成の確認

クローン、または、ダウンロードしたフォルダには以下のファイルが含まれています：

| ファイル名 | 説明 |
|-----------|------|
| Bob.svg | Bobのキャラクター画像。FAQサイトに挿入します |
| qa.md | FAQ質問集（英語）。日本語に翻訳してサイトに表示します |
| PROMPT.md | LAB1用のプロンプト集 |
| PROMPT2.md | LAB2用のプロンプト例 |
| AGENTS.md | Bobの挙動を指定します |
| .bobignore | Bobに確認させないファイルを指定 |

注意: PROMPT.mdはチャット画面へコピー&ペーストして使用するため、.bobignoreに記載されています。

## 3. IBM Bobの起動

デスクトップまたはアプリケーションフォルダから、IBM Bobを起動します。

## 4. フォルダを開く

### 4-1. フォルダーを開く

1. IBM Bob左上の「ファイル」メニューをクリック
2. 「フォルダーを開く」を選択

### 4-2. フォルダーを選択

1. 先ほどコピーした「Bob-workshop-main」フォルダに移動
2. フォルダをダブルクリックして中に入る
3. 「フォルダーの選択」をクリック

### 4-3. ファイルの確認

画面左側のEXPLORERに「Bob-workshop-main」が表示され、以下のファイルが確認できます：

- Bob.svg
- qa.md
- PROMPT.md
- PROMPT2.md
- AGENTS.md
- .bobignore

各ファイルをクリックして内容を確認してみましょう。確認後は、タブ右上の「×」ボタンで閉じます。

## チェックリスト

準備と設定が完了したら、以下を確認してください：

- 作業ディレクトリにフォルダをコピー済み
- IBM Bobを起動済み
- プロジェクトフォルダをBobで開いた
- ファイル一覧を確認済み
