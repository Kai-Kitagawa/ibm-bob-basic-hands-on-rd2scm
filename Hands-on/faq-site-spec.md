# FAQ サイト仕様書

## 仕様
- **種別**: 新規作成
- **目的**: qa.mdの内容を使用した、バックエンドなしの日本語FAQサイトを作成する
- **現在の挙動**: なし（新規作成）
- **期待する挙動**: 
  - ブラウザで直接開けるFAQサイト
  - カテゴリ別に質問が整理されている
  - 質問をクリックすると回答が表示される（アコーディオン）
  - 検索機能で質問・回答を絞り込める
  - レスポンシブデザイン対応

- **対象範囲**:
  - HTMLファイル（index.html）
  - CSSファイル（style.css）
  - JavaScriptファイル（script.js）
  - qa.mdの内容を日本語に翻訳してFAQデータとして組み込む

- **対象外**:
  - バックエンドサーバー
  - データベース
  - 外部ライブラリ・フレームワーク
  - 多言語対応（日本語のみ）

- **完了条件**:
  - 3つのファイルが作成されている
  - ブラウザでindex.htmlを開くとFAQサイトが表示される
  - すべてのFAQ項目が表示される
  - アコーディオンが動作する
  - 検索機能が動作する
  - レスポンシブデザインが適用されている

- **確認方法**:
  - ブラウザでindex.htmlを開く
  - 各質問をクリックして回答が表示されることを確認
  - 検索ボックスにキーワードを入力して絞り込みを確認
  - ブラウザウィンドウをリサイズしてレスポンシブ動作を確認

## 技術仕様

### ファイル構成
```
/faq-site/
  ├── index.html      # メインHTML
  ├── style.css       # スタイルシート
  └── script.js       # JavaScript
```

### データ構造
FAQデータはJavaScript内に配列として定義:
```javascript
const faqData = [
  {
    category: "カテゴリ名",
    items: [
      {
        question: "質問",
        answer: "回答"
      }
    ]
  }
]
```

### 機能詳細

#### 1. アコーディオン機能
- 質問をクリックすると回答が展開/折りたたみ
- 同時に複数の回答を開ける
- アニメーション付き

#### 2. 検索機能
- リアルタイム検索（入力中に絞り込み）
- 質問と回答の両方を検索対象
- 大文字小文字を区別しない
- 検索結果がない場合はメッセージ表示

#### 3. UI/UX
- シンプルで読みやすいデザイン
- カテゴリごとに視覚的に区別
- ホバー効果
- スムーズなアニメーション

#### 4. レスポンシブデザイン
- デスクトップ: 最大幅800px、中央配置
- タブレット: 幅に応じて調整
- モバイル: 縦スクロール、タップしやすいサイズ

### カテゴリと質問の翻訳

#### General（一般）
1. Bobとは何ですか？
2. Bobはどのように動作しますか？
3. Bobは何ができますか？
4. Bobで処理してはいけないデータ型はありますか？
5. Bobを使用するリスクは何ですか？

#### Usage（使い方）
1. 新しいタスクを開始するにはどうすればよいですか？
2. モード間を切り替えるにはどうすればよいですか？
3. ツールとは何ですか？どのように使用しますか？
4. コンテキストメンションとは何ですか？
5. Bobはターミナルでコマンドを実行できますか？
6. Bobにフィードバックを提供するにはどうすればよいですか？
7. Bobの動作をカスタマイズできますか？
8. Bobには自動承認設定がありますか？

#### Advanced Features（高度な機能）
1. MCP（Model Context Protocol）とは何ですか？
2. 独自のMCPサーバーを作成できますか？

#### Troubleshooting（トラブルシューティング）
1. Bobが応答しません。どうすればよいですか？
2. Bobが望まない変更を加えました。元に戻すにはどうすればよいですか？
